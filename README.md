# 撤退判断プロトタイプ

「進むか、降りるか」の判断が緊張感を生むかを検証するための、使い捨てプロトタイプ。
面白いゲームを作るのが目的ではなく、★撤退/続行の判断で実際に手が止まるかを人間が
20ラン回して確かめるためのもの（詳細は `prototype_spec.md` / `implementation_brief.md`）。

数値・定義はすべて設定ファイル（Python版 `config.py` / Godot版 `godot/config.gd`）に
集約してある。バランス調整はそこだけを編集する。性格・職業・エンチャント・人名は
配列に1行足すだけで追加できる。

## Python版（検証・バランス調整用の参照実装）

標準ライブラリのみ。CUI。

```bash
python3 main.py            # 普通に1ラン遊ぶ
python3 main.py --seed 42  # 乱数シードを固定（同じ展開になる）
python3 main.py --reset    # 墓地(graveyard.json)を初期化してから開始
```

- `graveyard.json` … 墓地（層ごとにスピリットを保持）。実行ディレクトリに生成。
- `runs.csv` … 1ラン1行の記録。ラン終了時に「迷ったか(1〜5)」を入力して追記される。

## Godot版（`godot/`）

Python版の忠実移植。ロジックは同じで、UIをテキスト主体の最小構成にしたもの
（アート・演出は未実装）。Godot 4.2 以降で `godot/project.godot` を開いて実行する。

墓地とログは Godot の `user://`（ユーザーデータ領域）に保存される。
コマンドラインからは以下のように起動できる。

```bash
godot --path godot -- --seed 42     # 乱数シードを固定
godot --path godot -- --reset       # 墓地を初期化
```

## 検証の見方

20ラン回して `runs.csv` を見る。判定基準は `prototype_spec.md` セクション7。
主に「撤退した層がばらついているか」「"迷ったか"が4以上のランが半数以上か」
「後半で墓地強化が効きすぎて作業感が出ていないか」を確認する。
